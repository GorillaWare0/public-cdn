# GorillaWare 4.4 soundboard sources

These are pre-made sound effects and music, downloaded from OpenGameArt. Each linked source page lists CC0, allowing redistribution. File names were changed for the soundboard; audio was not edited.

| CDN files | Creator | Source |
| --- | --- | --- |
| `Ghost/ghost-appearance.wav` | Ogrebane | [Ghost](https://opengameart.org/content/ghost) |
| `Ghost/scary-ghost.ogg` | Fupi | [Scary High-pitched Ghost](https://opengameart.org/content/scary-high-pitched-ghost) |
| `Ghost/ghost-moan-01.mp3` through `ghost-moan-05.mp3` | qubodup | [Ghost Monster Voice Moaning & Growling](https://opengameart.org/content/ghost-monster-voice-moaning-growling) |
| `Trolling/bubble-pop.wav` | EZduzziteh | [Pop sounds](https://opengameart.org/content/pop-sounds-0) |
| `Trolling/boing.mp3`, `Trolling/bing.mp3` | EZduzziteh | [Boings](https://opengameart.org/content/boings) |
| `Music/spooky-loop.mp3` | wipics | [Spooky Loop](https://opengameart.org/content/spooky-loop) |
| `Music/creepy-ambient.ogg` | epb9000 | [Creepy Ambient Loop](https://opengameart.org/content/creepy-ambient-loop) |

Every file is smaller than the menu's 32 MB playback limit. The menu caps remote voice transmission to the first 10 seconds of longer music and ambience clips.
