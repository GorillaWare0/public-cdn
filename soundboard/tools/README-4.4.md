# GorillaWare 4.4 soundboard pack

The 12 WAV files in `default/Ghost`, `default/Trolling`, and `default/Music` are generated by `generate_44_pack.py`. They use only synthesized tones and noise; no recordings, samples, character voices, or third-party music are included.

Run `python soundboard/tools/generate_44_pack.py` from any directory to regenerate the pack. Output is mono 16 kHz PCM WAV. The largest file is below 300 KB, and all files are under the menu's 32 MB playback limit. Music loops play locally for eight seconds; voice transmission remains capped by the menu.
